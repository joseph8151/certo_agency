## 규칙

- **비율 4:3** — 원본이 3:2 든 16:9 든 CSS `aspect-ratio:4/3` + `object-fit:cover` 로 중앙 크롭됩니다.
  중요한 인물이 화면 가장자리에 있으면 잘릴 수 있으니, 미리 4:3 으로 잘라 두는 편이 안전합니다.
- **모서리 2px** — `--radius-image` 토큰 한 곳에서 관리합니다.
- **이미지 위에 글자 없음. 어두운 오버레이 없음.** 그래서 사진 자체의 밝기가 그대로 보입니다.
- 권장 크기: 가로 1600px 이상, JPEG 품질 80 전후.
