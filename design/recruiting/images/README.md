## 규칙

- **비율 4:3** — 원본(1168×784, 3:2)을 CSS `aspect-ratio:4/3` + `object-fit:cover` 로 맞춥니다.
  좌우가 약 10% 잘리므로, 인물이 한쪽에 몰린 컷은 `index.html` 의 `style="--pos:…"` 로
  기준점을 옮겨 두었습니다. 사진을 바꾸면 이 값도 함께 확인하세요.

  | 파일 | `--pos` | 이유 |
  | --- | --- | --- |
  | 01 | `55% 50%` | 오른쪽 후보가 프레임 끝에 걸림 |
  | 02 | `56% 50%` | 강사와 화이트보드가 우측 |
  | 03 | `42% 50%` | 두 사람이 좌측 중앙 |
  | 04 | `50% 50%` | 중앙 정물 |
  | 05 | `58% 50%` | 강사가 우측 끝 |
- **모서리 2px** — `--radius-image` 토큰 한 곳에서 관리합니다.
- **이미지 위에 글자 없음. 어두운 오버레이 없음.** 그래서 사진 자체의 밝기가 그대로 보입니다.
- 권장 크기: 가로 1600px 이상, JPEG 품질 80 전후.
